📋 How to View Orders in phpMyAdmin

Step 1: Open phpMyAdmin

Click the "View Orders" button above or navigate to http://localhost:8080/phpmyadmin/

Step 2: Select Database

In the left sidebar, click on "jd_reporting_company"

Step 3: Open Orders Table

Click on the "orders" table from the list

Step 4: Browse Orders

Click the "Browse" tab to see all orders. You can filter, search, and export data from here.

🔍 Useful SQL Queries

Run these queries in the SQL tab of phpMyAdmin:

View all pending orders:

SELECT * FROM orders WHERE status = 'pending' ORDER BY created_at DESC;

Count orders by status:

SELECT status, COUNT(*) as count FROM orders GROUP BY status;

View today's orders:

SELECT * FROM orders WHERE DATE(created_at) = CURDATE();

📊 Order Data Fields

Each order contains the following information:

  • Order Number (e.g., JD-20251021-ABC123)
  • Client Name
  • Client Email
  • Client Phone
  • Service Type (legal/medical/zoom/academic)
  • Turnaround (same-day/24h/48h/3-5)
  • File Name
  • File Path
  • Duration (minutes)
  • Estimated Cost
  • Status
  • Special Instructions
  • Creation Date/Time
  • Deadline
  • Assigned To (transcriber)
  • Completion Date
